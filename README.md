# 🚗Used Car Price & Inventory Analysis Dashboard

An automotive analytics dashboard created to analyze used-car inventory, pricing, mileage, brands, revenue trends, and fuel types.

### 📌 Key Metrics

- **Total Unique Inventory:** 8096
- **Total Inventory Value:** 107M
- **Peak Inventory Price:** 38K

### 📊 Dashboard Insights

The dashboard analyzes:

- Monthly revenue trends
- Average mileage by brand
- Average price by brand
- Inventory by fuel type
- Brand-level performance
- Overall inventory value

### 🚘 Brands Analyzed

The dashboard includes brands such as:

- Audi
- BMW
- Dacia
- Fiat
- Ford
- Honda
- Hyundai
- Mercedes
- Toyota
- Volkswagen

### ⛽ Fuel Type Analysis

Inventory is segmented into:

- Petrol
- Diesel
- Hybrid

Petrol represents the largest share of the analyzed inventory.

### 📈 Brand Comparison

The average mileage and average price visualization allows comparison between different automotive brands.

This helps identify:

- High-priced brands
- High-mileage brands
- Lower-mileage vehicles
- Differences in average market pricing

### 💰 Revenue Analysis

Monthly revenue trends are visualized to identify changes in inventory value and pricing throughout the year.

### 🎯 Business Questions

This dashboard helps answer:

- Which brands have the highest average prices?
- Which brands have the highest average mileage?
- What fuel type dominates the inventory?
- How does inventory value change by month?
- Which brands may represent higher-value inventory?
- What is the overall value of the used-car inventory?
